Lambda Architecture Specification

              
Pemetaan alur pemrosesan Speed Layer (Streaming) dan Batch Layer sesuai Laporan Praktikum 2 & Worksheet 3

            

          


          

            

              
01 · DATA SOURCES

              

                

                  
STREAMING EVENT LOG

                  basket_details
                  
Log keranjang transaksi real-time (15.000+ record) untuk analisis pola waktu dan periode puncak.

                

                

                  
BATCH CATALOG & PROFILE

                  Tokopedia Catalog & customer_details
                  
29.519 data katalog produk semi-terstruktur dan 1.000 profil demografi pelanggan.

                

              

            


            
Ingestion & Storage Flow ↓


            

              
02 & 03 · INGESTION & STORAGE LAYER

              

                

                  
DISTRIBUTED MESSAGE BROKER

                  Apache Kafka
                  
Penyerapan stream transaksi berkapasitas tinggi secara fault-tolerant saat lonjakan trafik flash sale.

                

                

                  
NOSQL DOCUMENT STORE

                  MongoDB Data Lake
                  
Penyimpanan dokumen semi-terstruktur fleksibel dengan dukungan horizontal scalability.

                

              

            


            
Distributed Processing ↓


            

              
04 · PROCESSING LAYER (APACHE SPARK)

              

                

                  
SPEED LAYER

                  Spark Structured Streaming
                  
Pemantauan lonjakan pesanan harian, peak hours, dan metrik transaksi berlatensi rendah.

                

                

                  
BATCH LAYER

                  PySpark SQL & MLlib K-Means
                  
Regex parsing, kategorisasi NLP, join demografi, agregasi GMV, dan K-Means Clustering (k = 4).

                

              

            


            
Unified Serving Views ↓


            

              
05 · SERVING & PRESENTATION LAYER

              

                
REST API & ENTERPRISE BI FRONTEND

                FastAPI Backend + DATA INSIGHT Frontend (Apache ECharts)
                
Penyajian metrik teragregasi melalui REST JSON API asinkron dengan filter real-time dan import CSV dinamis.
